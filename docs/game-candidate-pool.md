### 最优方案：环线谜踪（Slitherlink）

**开发要点**

- 普通模式使用 5×5、困难模式使用 6×6 固定题库；题面只保存正确边线，数字线索由答案自动推导，避免网络、图片资源和题目生成器。
- 每条边循环“空白 → 发光路线 → 禁止记号 → 空白”；实时校验数字四边计数、分叉节点、开放端点和所有线段是否连成唯一闭环。
- 提示补上一条正确边线并扣 4 分；完整闭环后，普通最高 40 分、困难最高 50 分，保持 2–4 分钟内可完成。
- 通过 `getAwardedPoints()`、`addPointsToPet()`、`recordTrainingSession()` 发奖记档；作为可闯关项目，闯关模式只回传子局成绩，不单独发积分。

**适配改造建议**

- 采用“霓虹轨道图纸”：深蓝绿底、青绿交点、琥珀色已画路线；全部以 CSS 光晕和格线实现，不新增资源包。
- 开始页仅保留三条规则，首局优先展示 0、1、3 等可产生明显推理起点的线索；游戏中用“待满足 / 端点 / 提示”三项状态替代生硬错误弹窗。
- 边线点击区占据完整半格并允许叉记，避免要求拖拽或精确描边；困难只增加棋盘与隐藏线索，不靠缩短时间强压用户。

## 翻牌记忆

- 类型：短时记忆 / 位置记忆
- 核心玩法：短暂展示一组卡牌图案，翻面后玩家按要求找出匹配图案或复现位置。
- 适合训练：视觉编码、空间位置保持、抗干扰回忆。
- 难度方向：卡牌数量、展示时长、图案相似度、干扰卡数量。

## 点格棋

- 类型：规划 / 空间推理
- 核心玩法：在点阵上依次连线或占格，通过局部选择完成更高收益的路径。
- 适合训练：路径规划、局面评估、持续注意。
- 难度方向：棋盘尺寸、可选路径数量、阻挡点、回合限制。
