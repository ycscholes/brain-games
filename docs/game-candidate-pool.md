# 游戏备选池

## 翻牌记忆

- 类型：短时记忆 / 位置记忆
- 核心玩法：短暂展示一组卡牌图案，翻面后玩家按要求找出匹配图案或复现位置。
- 适合训练：视觉编码、空间位置保持、抗干扰回忆。
- 难度方向：卡牌数量、展示时长、图案相似度、干扰卡数量。

## 点格棋

- 类型：规划 / 空间推理
- 核心玩法：在点阵上依次连线或占格，通过局部选择完成更高收益的路径。
- 适合训练：路径规划、局面评估、持续注意。
- 难度方向：棋盘尺寸、可选路径数量、阻挡点、回合限制。

## 2026-07-22 轻量小游戏候选筛选

筛选原则：短局、低资源、无需新增图片资产，避开近期已实现或已筛掉的 Stroop、空间旋转、Hidato、单步视觉搜索和 Flanker/箭头干扰类玩法。本轮优先选择数字或格子约束推理，要求玩法在 4x4 到 6x6 小盘面内仍有多步判断，而不是只靠一次反应或单点匹配。

### 本轮选定方案：删数求和

删数求和总分最高。它把简单算术和行列约束结合在一个小盘面中，玩家每次保留或划掉一个数字都会同时影响横向和纵向目标，能提供比单步匹配更高的推理密度；同时不需要图片素材、复杂动画或大题库生成器，适合本项目轻量脑力训练定位。

落地细则：

1. 游戏结构：普通模式使用 4x4 固定题池，困难模式使用 5x5 固定题池；单局解一道完整盘面，强调完整推理而不是快速连答。
2. 交互方式：点击数字在“未定、保留、划掉”三态间切换；右侧和底部目标显示行列保留数字的目标和；提交后标出错误判断或结算。
3. 得分规则：普通满分 40，困难满分 50；基础分加速度与无失误奖励，错误提交扣分但最低保留 8 分，宠物积分继续通过共享 1.0 倍转换和普通/困难封顶。
4. 项目适配：新增 `sumplete-grid` 训练 ID、目录入口、分享文案、训练记录标题、最高分清理键、积分文档和单元测试；可进入游戏大闯关，但不列为首页热门。
5. 后续扩展：首版使用校验过的固定题库，后续可增加题目池或唯一解生成器；不在首版加入候选标注、提示系统或排行榜，避免体量扩张。
