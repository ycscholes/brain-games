## 2026-07-17 轻量化小游戏筛选

筛选约束：短局、低图片资源、适合微信小程序触屏操作；过滤体量过大、开发成本高、或只有单次视觉反应的浅玩法。本轮优先选择需要线索整合、路径规划或空间/逻辑推理的轻量游戏。

### 选定方案：密码推理 / Code Breaker

- 开发要点：每局 8 题；普通模式使用 3 位密码和 3 条反馈线索，困难模式使用 4 位密码和 4 条反馈线索；每题提供 4 个候选密码，只有 1 个满足全部线索。
- 适配改造：把传统 Mastermind 的连续自填猜测改为“读历史猜测反馈，选择唯一候选”，降低输入成本并压缩单局时长；反馈文案使用“位置正确 / 数字存在”替代黑白棋钉，适合低龄和泛用户理解。
- 积分方案：沿用轻量推理游戏 1.0x 转换，普通难度封顶 40，困难难度封顶 60；普通和困难均支持游戏大闯关回传。
- 资源体量：不新增图片资产，只使用数字芯片、线索卡和 CSS 反馈标签完成视觉表达。

## 翻牌记忆

- 类型：短时记忆 / 位置记忆
- 核心玩法：短暂展示一组卡牌图案，翻面后玩家按要求找出匹配图案或复现位置。
- 适合训练：视觉编码、空间位置保持、抗干扰回忆。
- 难度方向：卡牌数量、展示时长、图案相似度、干扰卡数量。

## 点格棋

- 类型：规划 / 空间推理
- 核心玩法：在点阵上依次连线或占格，通过局部选择完成更高收益的路径。
- 适合训练：路径规划、局面评估、持续注意。
- 难度方向：棋盘尺寸、可选路径数量、阻挡点、回合限制。
