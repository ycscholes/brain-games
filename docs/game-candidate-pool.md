# 游戏备选池

## 翻牌记忆

- 类型：短时记忆 / 位置记忆
- 核心玩法：短暂展示一组卡牌图案，翻面后玩家按要求找出匹配图案或复现位置。
- 适合训练：视觉编码、空间位置保持、抗干扰回忆。
- 难度方向：卡牌数量、展示时长、图案相似度、干扰卡数量。

## 点格棋

- 类型：规划 / 空间推理
- 核心玩法：在点阵上依次连线或占格，通过局部选择完成更高收益的路径。
- 适合训练：路径规划、局面评估、持续注意。
- 难度方向：棋盘尺寸、可选路径数量、阻挡点、回合限制。

### 本轮选定方案：逻辑破译

逻辑破译得分最高，原因是它用非常低的资源成本提供了明确的推理循环：提出假设、读取反馈、排除组合、修正下一次猜测。相比大盘面逻辑题，它更适合小程序用户在碎片时间完成一局；相比单步判断类游戏，它有持续推理和重复挑战价值。

落地细则：

1. 游戏结构：普通模式为 4 位、6 个符号、不重复、8 次机会；困难模式为 4 位、6 个符号、允许重复、7 次机会。
2. 交互方式：页面展示隐藏密码槽、当前猜测槽、符号盘和历史猜测。提交后反馈“命中”（符号与位置正确）和“错位”（符号存在但位置错误）数量。
3. 得分规则：成功破译给基础分、剩余次数奖励和快速奖励；未破译只按最佳接近度给少量分。普通良好表现约 24-40 分，困难经 1.5 倍积分倍率后封顶 60。
4. 项目适配：新增 `code-breaker` 训练 ID、目录入口、分享文案、训练记录标题、最高分清理键、积分文档和单元测试；可进入游戏大闯关，但不列为首页热门。
5. 视觉改造：使用无图片色块作为符号，反馈钉区分“命中/错位”，避免新增资产和包体压力。
