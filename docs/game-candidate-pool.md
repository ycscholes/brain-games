### 选定方案：网络回路 / Netwalk

选择原因：把“把所有终端接回中心服务器”作为单一目标，玩家每一次旋转都会改变网络的可达区域，形成真正的多步规划，而不是单次反应判断。它可用纯 CSS 表现线路和通电状态，不增加小程序资源包体；普通 `4 × 4`、困难 `5 × 5` 的固定树状题面可稳定校验并保持一局短小。

### 落地细则

- 开发要点：用独立逻辑模块保存每格的四向接口；点击仅顺时针旋转 90°；完成条件为所有接口双向对齐、无越界接口且从中心服务器 BFS 可达全部格子。每个难度提供 3 个预置题面和确定性的错位初态，避免上线首版引入唯一解生成器。
- 计分建议：完成局由基础分、速度奖励、少旋转效率奖励组成；每次提示扣 5 游戏分。普通最高 40 分、困难最高 50 分；宠物积分仅通过 `getAwardedPoints()` 和 `addPointsToPet()` 以 `1.0x` 进入普通/困难上限。
- 适配改造：内部 `gameId` 使用 `netwalk`，中文名“网络回路”；接入路由、游戏目录、分享、训练记录、最高分清理、积分文档和游戏大闯关。闯关子局只返回成绩及应得积分，不写单项记录或单独发放积分。
- 交互与视觉：采用深海控制台方向，服务器为暖琥珀色核心，已通电线路为青绿、断开线路为深蓝；点按后的线路旋转配合短促触感式缩放。提示直接旋转一个错误节点并聚焦它，降低新手理解成本。

### 选定方案：车阵突围 / Traffic Escape

选择原因：它以“让红车驶向出口”为单一、直观的目标，把空间规划拆成连续的小决策；每一步会立刻改变可移动空间，满足本项目“轻量但不浅”的标准。玩法只需要 CSS 车辆和网格，不新增包体资产，也避开了已实现的旋转辨形与连数路径。

### 落地细则

- 开发要点：普通模式使用 `5 × 5` 盘面，困难模式使用 `6 × 6`；车辆只沿自身朝向滑动；用独立逻辑模块校验边界、碰撞、通关与分数。首版各难度各准备 3 道精选题面，确保移动端题量轻、规则稳定。
- 计分建议：完成局按“基础分 + 速度奖励 + 调度效率 - 提示扣分”计算；普通最高 40 游戏分，困难最高 50 游戏分，宠物积分继续经 `getAwardedPoints()` 按 `1.0x` 换算并受普通/困难上限约束。
- 适配改造：内部 `gameId` 使用 `traffic-escape`，中文名为“车阵突围”；接入全部游戏、训练记录、分享、本地最高分清理和游戏大闯关。闯关时自动按全局难度开始，不单独写训练记录或发放子局积分。
- 交互与视觉：采用夜间城市路网与发光出口；点选车辆后显示对应的两个方向按钮，避免拖拽造成的误触；提示直接完成一步调度并扣分，帮助低龄或首次玩家理解“腾车让路”。

## 翻牌记忆

- 类型：短时记忆 / 位置记忆
- 核心玩法：短暂展示一组卡牌图案，翻面后玩家按要求找出匹配图案或复现位置。
- 适合训练：视觉编码、空间位置保持、抗干扰回忆。
- 难度方向：卡牌数量、展示时长、图案相似度、干扰卡数量。

## 点格棋

- 类型：规划 / 空间推理
- 核心玩法：在点阵上依次连线或占格，通过局部选择完成更高收益的路径。
- 适合训练：路径规划、局面评估、持续注意。
- 难度方向：棋盘尺寸、可选路径数量、阻挡点、回合限制。

### 选定方案：特征三连

选择原因：它满足本项目“轻量但不浅”的筛选标准。玩法不依赖图片资源，只需要卡牌符号和颜色；规则比已否决的目标搜索、箭头干扰更有多步归纳负荷；一局 8 题、每题 12 张卡，适合 1-2 分钟训练和大闯关接入。

### 落地细则

- 开发要点：实现 4 属性卡牌模型（数量、形状、纹理、颜色），三张卡在每个属性上必须全同或全不同才成立；题盘至少保证一个有效三连；选择满 3 张后自动判定。
- 计分建议：每题基础 4 分，快速答对 +1，连续答对 +1；每局 8 题，最高 48 分；宠物积分继续按 `1.0x` 进入普通/困难封顶。
- 适配改造：内部 gameId 使用 `triad-match`，中文名 `特征三连`；接入全部游戏、训练记录、分享、大闯关和本地最高分清理；不进入首页热门，避免改变首页推荐权重。
- UI 建议：卡牌保持固定 3 x 4 网格，三类视觉属性必须在小屏上可分辨；反馈时标出一个有效三连，降低规则学习成本。
