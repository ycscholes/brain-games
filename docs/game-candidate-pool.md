# 游戏备选池

## 翻牌记忆

- 类型：短时记忆 / 位置记忆
- 核心玩法：短暂展示一组卡牌图案，翻面后玩家按要求找出匹配图案或复现位置。
- 适合训练：视觉编码、空间位置保持、抗干扰回忆。
- 难度方向：卡牌数量、展示时长、图案相似度、干扰卡数量。

## 点格棋

- 类型：规划 / 空间推理
- 核心玩法：在点阵上依次连线或占格，通过局部选择完成更高收益的路径。
- 适合训练：路径规划、局面评估、持续注意。
- 难度方向：棋盘尺寸、可选路径数量、阻挡点、回合限制。

## 2026-07-19 轻量小游戏候选筛选

筛选原则：短局、低资源、无需新增图片资产，避开近期已实现或已筛掉的 `code-breaker`、`inequality-grid`、Stroop、空间旋转、Hidato、单步视觉搜索和 Flanker/箭头干扰类玩法。本轮优先选择能在手机上完成约束推理、但不需要大盘面候选数字管理的轻量游戏。

### 本轮选定方案：帐篷营地

帐篷营地总分最高。它能把空间排除、行列计数和局部相邻约束压缩在 6x6/7x7 棋盘里，适合小程序短局训练；同时不依赖图片素材，只有树格、帐篷格和计数栏，开发与包体成本可控。

落地细则：

1. 游戏结构：每局 4 题。普通模式使用 6x6 棋盘、5 顶帐篷；困难模式使用 7x7 棋盘、6 顶帐篷。
2. 交互方式：点击非树格切换帐篷，行列数字实时显示是否满足数量；提交后展示正确帐篷位置并短暂停留。
3. 得分规则：每题正确基础 7 分，快速奖励 1-2 分，连续答对 2 题以上加 1 分；整局满分约 40，困难积分继续通过共享 1.5 倍倍率封顶 60。
4. 项目适配：新增 `tents-camp` 训练 ID、目录入口、分享文案、训练记录标题、最高分清理键、积分文档和单元测试；可进入游戏大闯关，但不列为首页热门。
5. 后续扩展：当前使用校验过的固定轻量题库，后续可增加题库或引入唯一解生成器，但不应在首版加入复杂候选标注系统。
