# 环线谜踪 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 环线谜踪 (Slitherlink), a CSS-only constraint puzzle with normal/hard boards, shared rewards, records, sharing, catalogue visibility, and gauntlet support.

**Architecture:** Keep the puzzle model and all rule evaluation in `src/pages/loop-line/gameLogic.ts`; the page only owns UI phase, timer, audio, hints, and the shared reward flow. Puzzle templates store a closed-loop edge solution and derive visible clue counts, allowing deterministic mobile-friendly boards without a generator or image assets.

**Tech Stack:** Taro + React + TypeScript, Jest, SCSS, existing training storage and gauntlet helpers.
