# 环线谜踪入口与目录统一设计

## 目标

使环线谜踪的开始页沿用 24 点已使用的通用浅色入口骨架，使它在“全部游戏”中的卡片与其他卡片保持一致；同时将推理分组的目录顺序固定为：连数迷阵、帐篷营地、环线谜踪、车阵突围、网络回路。

## 范围

- 仅改造环线谜踪的 `start` 阶段：使用 `start-screen`、`header-section`、`rules-card`、`summary-card` 和底部悬浮开始操作的既有结构与样式语义。
- 保留环线谜踪的规则内容、普通/困难选择、最高分读取、闯关预设自动开始，以及游玩和结算阶段的现有行为与棋盘高对比视觉。
- 移除环线谜踪专属的目录卡片外观覆盖，让 `card-loop-line` 继承共享游戏列表卡片样式。
- 在目录优先级中为五项指定推理游戏给出连续且显式的顺序，并用单元测试锁定该顺序。

## 实现与验证

开始页不修改计分、奖励或训练记录调用；因此 `docs/points-economy.md` 无需变更。目录顺序仍从 `ALL_GAME_ITEMS` 派生，首页推理组继续按该同一来源展示。

新增或更新目录测试，断言推理游戏的前五项 ID 顺序。运行对应测试、全量测试、类型检查、lint、微信小程序构建、密钥检查和 `git diff --check`。
