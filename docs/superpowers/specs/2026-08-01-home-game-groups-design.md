# 首页游戏分组与排序设计

## 目标

首页卡片在每个分组内与“全部游戏”页面使用同一排序结果。首页新增“推理”分组，并仅显示四个指定游戏：连数迷阵、帐篷营地、网络回路、车阵突围。

## 方案

游戏目录继续是分类、全部游戏排序和首页展示的唯一数据源。

- `ALL_GAME_ITEMS` 保持为全部游戏页面的排序结果。
- 新增首页分组配置：现有首页展示分组沿用原有热门游戏，推理分组显式列出四个游戏并限制为四项。
- 首页从 `ALL_GAME_ITEMS` 过滤得到各组卡片，因此同组顺序永远与全部游戏一致。
- `isHot` 仍只用于推荐权重与原有热门语义，不因首页展示分组而改变。

## 范围与兼容性

本次只改变首页卡片分组和显示顺序。不改变游戏路由、训练记录、积分、难度、闯关候选池或全部游戏页面。

## 验证

为目录单元测试补充首页分组断言，覆盖推理组的四个游戏和其排序。运行对应测试、类型检查、lint、微信小程序构建、密钥检查与 `git diff --check`。
