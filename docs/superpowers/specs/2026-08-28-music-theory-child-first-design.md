# 音符小探险儿童优先改版设计

## 目标

让低识字音乐初学者靠图形、操作和即时反馈完成学习；恢复可靠的真拖拽，同时保留点选回退。

## 已确认设计

- 使用推荐的“温柔引导”：目标槽位缓慢呼吸，答对出现星星，答错只轻摇并留在当前题。
- 题干、按钮和反馈改为 2–4 字优先；音名、题号和音乐符号是主要信息。较长解释不再显示在游戏过程中。
- 拖动卡片时页面显示跟随手指的音符影子；以 `onTouchStart` / `onTouchMove` / `onTouchEnd` 传递真实页面坐标，使用已测量的 `.staff` 边界转为局部坐标。只有释放点在槽位内才判定。
- 点击回退与拖放调用同一个“音名 + 槽位”判定函数；测量未完成或离开谱面均只给出简短引导，不会误判。
- 仅添加 CSS / Unicode 动效，不增加图片、音频或依赖；`prefers-reduced-motion` 下停止循环动画。

## 范围

修改 `src/pages/music-theory/index.tsx`、`index.scss` 和现有逻辑测试；不改变题库、分数、积分、训练记录、目录、分享或闯关契约。

## 验收

1. 游戏中没有长段解释；主操作文案为“选音符”“放这里”“对了”“再试”。
2. 拖动时卡片影子跟随触点；在目标释放才正确，非目标或谱外释放错误且可重试。
3. 点击回退仍可完成同一题，且与拖放使用同一局部坐标换算和判定。
4. 目标呼吸、答对星星、错误轻摇可见；reduced-motion 下无循环/大幅动画。
5. 逻辑测试、全量测试、typecheck、lint、build:weapp、secrets 检查与 diff 检查通过。
