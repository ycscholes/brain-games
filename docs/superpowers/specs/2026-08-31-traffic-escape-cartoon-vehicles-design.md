# 车阵突围卡通车辆素材设计

## 目标

将棋盘内现有的纯色 CSS 车辆替换为统一风格的卡通跑车图片，提高移动端辨识度与游戏表现力；不改变题面、移动、碰撞、难度、计分或积分规则。

## 视觉方向

采用「活力跑车」：圆润车身、高饱和配色、可见轮胎与朝向清晰的车头。红色目标车保留最强视觉优先级，并使用高光与显眼车头强化出口目标。

## 资源方案

- 生成一张透明背景 PNG 精灵图，包含 target、amber、cyan、violet、lime、coral 六种跑车。
- 资源保存到 `asset-backups/cloudbase-images/assets/games/traffic-escape/`，通过项目的 CloudBase 资源流程上传并使用远程路径。
- UI 通过车辆颜色映射为精灵图位置；横向车辆显示原始朝向，竖向车辆旋转 90 度。
- 图片未就绪或加载失败时，车辆继续显示现有 CSS 纯色车身，保障可玩性。

## 页面接入

- `traffic-escape/index.tsx` 只增加车辆视觉映射和图片元素，不触碰 `gameLogic.ts`、移动事件或状态结构。
- `traffic-escape/index.scss` 保留现有纯色样式作为降级层；卡通图片采用 `object-fit: contain`，留出与棋盘格线和选中描边的安全间距。
- 已选中和提示动画继续作用在车辆容器，因此触控范围、提示表现和无障碍语义保持一致。

## 验收与验证

- 覆盖六种颜色到精灵资源定位的映射测试，防止新题目车辆回退为错误图片。
- 运行相关单测、全量测试、类型检查、lint、微信小程序构建、资源检查、密钥检查与 `git diff --check`。
- 在微信开发者工具或真机确认横竖车辆不变形、选中状态可见、图片未加载时仍可正常移动。
