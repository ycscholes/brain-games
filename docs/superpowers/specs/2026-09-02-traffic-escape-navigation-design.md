# 车阵突围页面背景与返回入口设计

## 目标

优化车阵突围的移动端页面体验：修复游戏首页底部出现黑色的问题，并让进行中的游戏可以明确返回车阵突围首页。

## 方案

- 将 `traffic-escape-page` 的背景色作为页面唯一底色，并让开始页的滚动容器使用同一颜色，避免根容器与内容容器之间出现底色断层。
- 在 `playing` 状态的顶部 HUD 增加“返回首页”按钮。按钮只负责返回当前游戏的难度选择首页；若正在进行一局，则按现有训练记录/积分管线记录为 `interrupted`，避免退出造成状态遗漏。
- 返回后清理本局运行状态（计时、提示、棋盘和完成标记），不改变最高分和难度选择逻辑。

## 交互与边界

- 仅游戏进行中显示返回按钮；结果页继续使用已有“返回难度选择”。
- 返回按钮使用触摸安全尺寸和现有页面视觉语言，不引入新图片资源或新路由。
- 军团挑战模式下沿用 `completeGauntletLegIfNeeded` 的中断处理；若该流程接管导航，则不重复设置页面状态。

## 验证

- 增加/调整单元测试，覆盖中断返回的记录与状态清理行为。
- 运行车阵突围相关测试、类型检查、lint、微信小程序构建及 `git diff --check`。
