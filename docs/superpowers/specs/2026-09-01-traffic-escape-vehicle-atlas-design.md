# 车阵突围：无底色车辆精灵图

## 目标

车阵突围的棋盘仅用车辆图案表达占位，移除现有 CSS 车辆的渐变底色、边框、伪车窗与颜色块。两格车和三格车都要完整填满各自的占格范围；竖向车辆从同一横向车辆图案整体旋转，不拉伸、不裁断。

## 单图资源

- 将现有六张透明 PNG 裁去四周多余透明像素，保留完整车身、轮胎和阴影。
- 合成为一张透明 PNG：第一行是三辆两格车，每个图块为 `2:1`；第二行是三辆三格车，每个图块为 `3:1`。
- 图集统一宽度为三个图块宽：两格行图块高为图块宽的一半，三格行图块高为图块宽的三分之一。页面以整张图宽的三倍显示，因此每个图块恰好映射为所属车辆的横向边界。
- 图集保存为 `asset-backups/cloudbase-images/games/traffic-escape/vehicle-atlas.png`，上传到 CloudBase 的 `assets/games/traffic-escape/vehicle-atlas.png`；旧的六张单车资源保留在备份目录，不再由页面请求。

## 渲染规则

1. 远程资源表只解析图集的一个 URL，进入棋盘后不再按车型请求六个独立文件。
2. 每辆车的内部视窗根据 `appearance` 选择图集列，并按 `length` 选择两格或三格行。使用同一图集 URL 的图像元素进行裁切；其余实例复用同一资源缓存。
3. 横车视窗与车辆网格边界等大。竖车先建立相同长度的横向视窗，再居中旋转 90 度，故两格竖车为 `1:2`、三格竖车为 `1:3`，不压缩车头或车身。
4. 车辆容器仍承载点击、选中描边和提示动画；图片加载失败时仅保留可见的轮廓/标识降级样式，不能恢复彩色矩形底板。

## 不变项

- 车辆位置、朝向、碰撞、解法、难度、得分与积分均不变。
- 目标车、车型分配和“一局三种形态都先出现”的既有逻辑不变。

## 验收

- 六种车型均从同一张图集中正确裁切；两格和三格横车完整显示且长度比例正确。
- 两格、三格竖车分别完整占据 `1:2`、`1:3` 的格子范围，车身不变形。
- 棋盘中的车辆不再显示渐变底色或 CSS 伪车身；选中和提示状态仍可见、拖动/点击范围不变。
- 资源检查、相关单元测试、全量测试、类型检查、lint、微信构建、密钥检查和差异检查通过；上传后确认 CloudBase 中仅由图集 URL 驱动页面加载。
