# 训练成绩贴图海报设计

## 目标

用户点击普通游戏结算页的“晒出本局成绩”后，自动生成一张包含游戏名称、得分和贴图奖励说明的本局成绩海报，并在微信官方账号发表页中预填该图片。

## 设计

- 使用小程序隐藏 `canvas` 绘制海报，而非截取页面 UI；这避免页面结构、滚动位置和原生组件导致的截图不一致。
- 海报由统一组件承载，固定绘制 750 x 960 逻辑像素：品牌标题、游戏名、显著得分、鼓励文案与“Cici 脑力训练”落款。
- Canvas 导出为临时 PNG 后，作为 `wx.shareToOfficialAccount` 的 `images` 参数传入；正文、话题和推荐小程序路径保持现有行为。
- Canvas 不可用、绘制或导出失败时，继续打开纯文字发表页；只有发表成功且包含 `postUrl` 才发放积分。
- 仅 iOS/Android 真机执行海报生成；开发者工具、桌面端和 HarmonyOS 已有的平台拦截不变。

## 验收

1. 真机点击后，发表页自动带入一张成绩海报。
2. 海报导出失败不阻止文字发表，也不提前发放积分。
3. 现有发表成功、取消、平台不支持和每日奖励上限行为不变。
4. 单元测试覆盖图片参数传递与导出失败降级。
