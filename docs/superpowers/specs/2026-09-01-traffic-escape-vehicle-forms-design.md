# 车阵突围：分尺寸车辆形态

## 目标

为车阵突围按占格长度提供可辨识的卡通车辆形态：两格车辆和三格车辆各有三种。游戏中的车辆先覆盖所属长度的全部形态，只有数量超过三种时才随机重复。

## 资源

- 两格小车：保留现有跑车形态，新增小面包车与城市出租车。
- 三格大车：新增城市巴士、箱式货车与加长轿车。
- 新增的五张资源均为无文字、透明背景的卡通 PNG，保存在 `asset-backups/cloudbase-images/games/traffic-escape/`，并同步到 CloudBase 的同一路径；现有跑车资源作为第六种形态继续使用。

## 数据与渲染

- 车辆新增 `appearance` 字段，其值是与占格长度对应的三种形态之一；颜色仍用于车身配色和红车目标标识。
- 远程资源表按 `length + appearance` 解析 URL；加载失败时继续显示现有 CSS 车辆兜底。
- 创建题目和固定题库均通过同一个形态分配函数处理，不影响车位、朝向、解法或难度要求。

## 分配规则

1. 普通和困难局都至少放入三辆两格车、三辆三格车；普通局棋盘随之调整为低密度 6×6，目标红车固定使用现有跑车形态。
2. 除目标车外，按长度分别收集车辆；每组先以打乱顺序分配三种形态，确保一局覆盖对应长度的全部三种。
3. 同一长度的第 4 辆及以后从三种形态中随机选择，允许重复。
4. 对相同种子使用确定性随机源，保证题目与形态可复现。

## 验证

- 单元测试证明两格、三格车辆各自先覆盖全部三种形态，且超出三辆时仅从所属形态池随机重复。
- 既有题目和随机题目仍可求解，评分与积分规则不变。
- 运行测试、类型检查、lint、微信构建、资源检查与 CloudBase 上传。
