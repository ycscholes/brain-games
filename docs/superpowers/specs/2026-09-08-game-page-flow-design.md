# 游戏三页流程迁移规范

## 页面职责

- `index` 是游戏起始页，也是目录、分享和历史链接的稳定入口。
- `play` 只承载一局进行中的交互；返回会结算为 `interrupted` 并回到起始页。
- `result` 只展示已封存的完成结果；以替换导航进入，系统返回回到起始页，不恢复已完成棋局。

## 会话边界

每局创建一个由 `gameId + runId` 标识的本地流程会话。会话只接受 `active → settled` 或 `active → abandoned` 的一次状态迁移；玩法自行定义 JSON payload，公共工具不理解题面和 UI 字段。

大闯关保留其既有会话和跳转：子游戏直接进入 `play`，完成或中断回大闯关，不显示单局 `result`。

## 迁移次序

先迁移推理棋盘类，再迁移多阶段记忆与追踪类，最后迁移计时答题和语言类。每批完成后回归该批游戏的普通入口与大闯关入口。
