# 游戏下线与玩法分类设计

## 目标

完整下线“逻辑破译”（`code-breaker`）和“大小迷阵”（`inequality-grid`），并移除“日常优先”这一使用频率导向的分类。游戏列表改为按核心玩法模式分组，帮助玩家根据想训练的能力选择游戏。

## 分类模型

`GameCategoryId` 改为下列五个唯一分类，列表顺序即展示顺序：

| 分类 ID | 标题 | 游戏 |
| --- | --- | --- |
| `math` | 计算与数理 | 速算挑战、24 点 |
| `memory` | 记忆与反应 | 数字广度记忆、逆向猜拳、颜色陷阱、星链回响、奇趣记忆、追踪任务、农场清点 |
| `reasoning` | 推理 | 找规律、旋影辨形、特征三连、连数迷阵、帐篷营地、删数求和、车阵突围 |
| `language` | 语言 | 词语拼盘 |
| `challenge` | 综合挑战 | 游戏大闯关 |

分类只表达游戏的主要玩法模式，不表达难度、推荐优先级或热度；原有 `level` 和 `isHot` 字段保留其既有用途。

## 下线范围

彻底删除两个游戏的页面目录（页面、样式、逻辑）及其测试，并从以下共享入口移除引用：

- 应用页面注册和游戏目录；
- 训练记录 `TrainingGameId`、游戏标题映射和游戏大闯关候选；
- 分享、样式及所有仅服务于这两个页面的配置；
- 积分经济文档中的奖励规则和 gameId 规范。

历史本地训练记录不迁移或清除：它们仍留在本地数据中，但因为游戏已无目录条目，将不再作为可进入游戏展示。

## 实现与验证

游戏目录仍从 `GAME_CATALOG` 和 `GAME_CATEGORIES` 生成分组，因此分类变化集中在目录配置，并保持首页与“全部游戏”页的一致排序。更新受影响的单元测试（包括闯关可选游戏数量及已移除 gameId 断言），再执行受影响测试、类型检查、lint、微信小程序构建、密钥检查与 `git diff --check`。

## 非目标

- 不改变其余游戏的计分、难度、宠物积分或闯关抽取规则。
- 不清除用户本地历史训练记录。
- 不新增游戏或更改现有页面视觉样式。
